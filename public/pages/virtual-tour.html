360°-Rundgang mit Insta360 X4

Entdecken Sie unsere Fertigung, Prüffelder und Servicebereiche interaktiv. Die Tour basiert auf einem Insta360 X4 Rundgang, der sich bei Bedarf jederzeit aktualisieren lässt.

So funktioniert die Tour

Nutzen Sie Ihre Insta360 X4, um einen equirektangulären 360°-Export (JPG oder PNG) oder eine per Insta360 Studio veröffentlichte Tour einzubinden. Die Vorschau unten lädt standardmäßig ein Platzhalterbild; ersetzen Sie es durch Ihre eigenen Aufnahmen, um Besucherinnen und Besucher durch Ihr Unternehmen zu führen.

  • Unterstützt 360°-Fotos (JPG/PNG) aus Insta360 Studio oder der Insta360 App.
  • Optionaler Deep-Link zu einer gehosteten Tour oder einem 360°-Video Ihrer Wahl.
  • Anleitung im unteren Bereich erklärt die Aktualisierung mit neuen Aufnahmen.

Der Platzhalter wird angezeigt. Laden Sie Ihre Insta360-Aufnahme wie unten beschrieben hoch.

Eigene Insta360 X4 Aufnahmen integrieren

  1. 360°-Foto exportieren: Öffnen Sie Ihre Aufnahme in Insta360 Studio und exportieren Sie ein equirektangulares JPG (2:1 Seitenverhältnis, z. B. 7680×3840 px).
  2. Datei ablegen: Speichern Sie die Datei im Projekt unter public/tour/ und benennen Sie sie beispielsweise werksrundgang.jpg.
  3. Verweis anpassen: Passen Sie im HTML oder über das Admin-Deployment die data-panorama-Angabe dieses Abschnitts auf Ihre Datei an (z. B. /tour/werksrundgang.jpg).
  4. Optional: Online-Tour einbetten. Wenn Sie eine Insta360-Webtour hosten, ersetzen Sie stattdessen den Platzhalter durch einen iFrame-Link; Hinweise finden Sie in der README unter „Virtueller Rundgang“.

Mehrere Perspektiven lassen sich kombinieren, indem Sie zusätzliche Viewer-Container hinzufügen oder aus dem Viewer heraus Hotspots definieren. Die aktuelle Integration nutzt Photo Sphere Viewer und unterstützt Gestensteuerung auf Mobilgeräten sowie Vollbild-Darstellung am Desktop.
